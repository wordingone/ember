# Ember authority conservation matrix

This is the executable D-001-through-D-062 conservation matrix required by
docs/domains/governance/authority/GOAL.md. The legacy six-column M/C completeness manifest remains intact at
`docs/domains/governance/contracts/ember-completeness.md` for diagnostic parsing and evidence custody; it
is historical and is not the current authority denominator.

Disposition semantics:

- ENFORCED: the recovered correction has one or more live enforcing surfaces.
- HISTORICAL_ONLY: the row preserves a fact about prior artifacts or reporting
  and grants no current execution, lineage, capability, or completion credit.
- OPEN_RESEARCH: the requirement or research family is conserved, while a
  technical mechanism, regime, or proof remains unresolved.

A row may have multiple dispositions because one discrepancy can contain a
historical fact, an enforced correction, and an open technical question. An
ENFORCED row must name real repository files. Presence in this matrix is not
evidence that the downstream model or capability exists.
